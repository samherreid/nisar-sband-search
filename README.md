# sband-search

Programatically access NISAR S-band data from Bhoonidhi.

Example for Antartica

In the notebook we build a frame directory, chose frames and then download.

You will need credentials from https://bhoonidhi.nrsc.gov.in/bhoonidhi/login.html

which you can set with

```bash
export BHOONIDHI_USER='your_user_id'
export BHOONIDHI_PASSWORD='your_password'
```

or omit this and be prompted interactively.
